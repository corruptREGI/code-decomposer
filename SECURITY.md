# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's private vulnerability reporting feature on this repository (the **Report a vulnerability** button on the Security tab). Include steps to reproduce and the potential impact where possible.

Do not include API keys, access tokens, or real user data in a report. If a secret was exposed, revoke or rotate it with its provider immediately, then report the exposure privately.

## Supported versions

Only the latest version on the default branch is currently supported. There are no published release branches yet.
