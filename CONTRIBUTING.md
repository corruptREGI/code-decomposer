# Contributing

Thanks for considering a contribution to Code Decomposer (EcoRoute Lite).

## Before you start

- Search existing issues and pull requests to avoid duplicating work.
- For a significant change, open an issue first to discuss the approach.
- Never include API keys, credentials, or private user data in a change, issue, or log.

## Make a change

1. Fork the repository and create a focused branch.
2. Install dependencies with `npm install` and create a local `.env` from `.env.example` if needed.
3. Make the smallest change that addresses the issue and update documentation when behavior changes.
4. Run `npm run lint` and `npm run build` before opening a pull request.
5. Open a pull request with a clear summary, the reason for the change, and any relevant screenshots or manual verification notes.

## Pull requests

- Keep unrelated changes in separate pull requests.
- Explain user-visible changes and any configuration changes.
- Do not add generated output, dependency directories, secrets, or unrelated formatting churn.
